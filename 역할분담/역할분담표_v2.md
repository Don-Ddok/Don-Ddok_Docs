## 역할별 상세

### ① 여신·업종 대출

**목표** · 대출 쪽 결론을 "약한 증거" 그대로 정직하게 굳히고, 쟁점 1(업종 상쇄는 확정 발견인가)을 판가름

1. 부호 해석 통일 — β₃ = −0.231은 "노출 법인은 대출 유지, 비노출이 줄임"(β₁ +0.19, β₁+β₃ −0.04)으로 통일. 9/28 보강 계획 문서의 해석 수정
2. 목표 문구 수정 — "p<0.05 확보" 대신 "사전 고정한 방법으로 정직하게 보고"
3. 9단계 실행 — 9-1 하락 국면 β₃⁻, 9-2 노출 강도, 9-3 수출 회사만, 9-4 균형 패널. Holm 보정으로 판정
4. 달력 통제 한 줄 추가 — 주 결과에 "노출×영업일수" 통제를 넣은 강건성 결과. 실행 전에 문서에 먼저 고정 (④의 변수 사용)
5. 표7 재추정 — 결과보고서 업종 회귀를 달력 통제 + 이중 군집 + 시차 구간 평균으로 다시 돌리고, 파트 3의 6단계 결과와 나란히 제시. 유지되면 확정, 아니면 탐색적

**산출물** · 06 문서 결과 절, 달력 통제 결과 한 줄, 쟁점 1 판정 한 줄

**하지 않을 것** · 새 결합검정을 주 결과로 쓰기(쓰더라도 "사후 보조" 표시) · 결과 보고 업종 다시 고르기 · PSM·wild bootstrap 재작업(이미 완료)

### ② 저축성 예금 (거치식·적립식)

**목표** · 팀에서 유일하게 저축 채널을 본 결과를 다른 파트와 비교 가능한 형태로 만들기

1. 대조군 추가 — 비노출 법인을 넣어 팀 표준 식(S×D, β₃)으로 재추정. 지금은 처치군만이라 사실상 대구 대 경북 비교가 됨
2. 처치 정의 정리 — 팀 표준(36개월 중 1회 이상)으로 바꾸거나, rolling 정의를 유지할 경우 차이와 한계(2023년 전체 창 불완전, 수출 중단 기업 이탈) 명시
3. 대상 축소 — 기계·도매·1차 금속 3개 업종만. 달력 통제 포함
4. 표기 보완 — 표준오차 종류 명시, 부호 뜻 확인, "완벽히 대변", "부실화 전조" 등 표현 완화

**산출물** · 업종 3개 × 거치·적립 확정판 표(전부 "탐색적" 표시)

**하지 않을 것** · 새 업종 추가

### ③ 요구불 신호

**목표** · 쟁점 3(은행 데이터는 공식 통계보다 빠른가)을 판가름. 남으면 "관측 시점 격차", 사라지면 "착시로 판명" 사례

1. 영업일수 보정 재계산 — 자금압박지수와 리드타임 (④의 변수 사용) → "보정 전 68% / 보정 후 ?%"
2. 비대칭 검정 이중 군집 재확인 — 깊은 하락 월이 대구 6개·경북 4개뿐이라서. 결론(비대칭 없음) 불변 확인용
3. 등급 표시 — "대구 한정"은 결과를 본 뒤 고른 조건이므로 탐색적. 업종 신호 사전도 다중검정 미보정이라 탐색적
4. 문서 수정 — 컷오프 문단 평균값 마이너스 부호, 라벨 오타

**산출물** · 보정 전후 비교표 1개, 이중 군집 결과 한 줄

**하지 않을 것** · 대구 한정 결과를 확정처럼 쓰기

### ④ 데이터·대시보드

**목표** · 모든 파트가 같은 달력 변수를 쓰게 하고, 사이트가 보고서와 다른 말을 하지 않게 만들기

1. 영업일수 변수 검증·배포 — 공휴일 목록(수기 입력)을 공식 달력과 대조한 뒤 ①②③에 파일 배포 (9/29, 가장 급함)
2. 외부 데이터 점검 — 옛 환율 파일(52/60개월 불일치)을 쓴 파트가 있는지 확인, BSI 원자료 대조 후 공지
3. 대시보드 최소 수정 — 조건 1에 영업일수 보정 여부 표시, 계정 시차 화면의 "조기경보 후보" 문구 수정, PRODUCT.md의 근거와 발표일(10/7) 갱신
4. 여유 있으면 — 첫 화면에 노출 대 비노출 요구불 격차(포트폴리오 뷰)

**산출물** · 영업일수 변수 파일, 데이터 점검 공지, PR 1~2개

**하지 않을 것** · 조합 추가, 문턱 조정 · 공개 사이트에 실제 데이터 기반 새 수치 추가

### ⑤ 통합·보고서·발표

**목표** · "우리 분석 안에서도 착시를 찾아 걷어냈다"는 하나의 이야기로 묶기

1. 공통 판정표 틀 배포 — 결과마다 한 줄, 열은 이중 군집 p · 사전추세 · 달력 통제 · 사전 설계 여부 · 표본 수 · 등급 (9/29)
2. 표현 가이드 공유 — 파트 3의 "써도 됨 / 쓰면 안 됨" 가이드를 팀 공통으로 (9/29)
3. 보고서 개정 — 표지 기수·기간(9기, 09.21~10.07), 인사이트 2 수위 조정, 파트 3 매칭 결과(약한 증거) 추가, 거치·적립 결과 반영, 증거 사다리 삽입
4. 발표자료 — 가설(기획서) → 착시를 걷어낸 과정 → 증거 사다리 → "돈은 어디서 빠지고 어디로 메워지나" 표 → 실무 제언 → 한계·향후 과제
5. Q&A 시트 — ①~④가 각자 예상 질문 3개와 답을 제출하면 취합

**산출물** · 판정표 최종본, 보고서 개정판, 발표자료, Q&A 시트

## 팀 전체가 하지 않을 것

- 결과를 본 뒤 방법을 바꿔 p를 낮추기. p=0.094와 검정력 39%는 "확정 불가"로 그 자체가 발표할 결과다.
- 새 계정 조합, 새 업종, 새 지표 탐색. 아이디어 A·B·C·4·5, 품목별 수출은 "향후 과제" 슬라이드로.
- "조기경보", "유의하다", "공식 통계보다 빠르다", "불황기 자금압박 기업 11%" 같은 표현.
