## 금일 작업 내용

### 파트3 분석 반론 점검

- 남아 있던 반론 세 가지(수출이 꺾이기 전 6개월의 사전 추세, 기준금리 통제, 달력월(계절) 더미)를 점검 — 기준금리·계절로는 주 결과가 설명되지 않아 주 결과(β₃ −0.231, p 0.094)는 "약한 증거"로 유지
- 다만 사전 추세에서 꺾이기 전에도 비슷한 차이(p 0.095)가 보여, "꺾인 뒤에 갈라졌다"는 시간 순서는 확정할 수 없다는 한계를 새로 확인

### 분석 자료 시각화 및 웹사이트 개편

- 분석 전체 지도 1장, 분석별 그림 22장, 전체 정리 PPT 34장, 팀 PPT용 표지·내지 배경을 제작해 Docs 저장소에 업로드

- "캠페인" 문구를 "이번 달 추천"으로 바꾸고, 변수·지표를 쉬운 말로 풀어 쓴 용어 사전 탭(35개)을 추가(Dashboard #29), 노션용 용어 사전 문서도 별도 제작

### 저축성 예금 분석 재설계

- 리뷰를 반영해 대조군을 넣고 "노출−비노출 격차"로 다시 분석 — 처치군만 볼 때는 기계(자금 소진형)·도매(방어형)·1차 금속(무반응형)으로 보였으나, 대조군을 넣자 도매는 차이가 없고 1차 금속이 오히려 가장 뚜렷하게 반응해, 같은 시기 모든 법인에 있던 변화를 업종 특성으로 착각했음을 확인
- rolling 기준 처치 정의는 수출 충격으로 수출을 멈춘 회사가 처치군에서 빠져 "결과가 처치를 바꾸는 구조"임을 확인
- 강건성 검정에서 잔액 양수 관측만 쓰면 효과가 사라져 보유 여부로 직접 확인 — 1차 금속의 결과는 잔액 증가가 아니라 계좌를 여는 쪽의 변화임을 확인

### 요구불·대출·예금 분석 통합 및 데모 웹 개선

- 요구불 분석·파트3 대출 분석·예금 분석을 PDF 하나로 통합 — 수출이 꺾이면 수출 회사의 통장 잔고는 줄고 적금은 늘어나는 모습을 확인(탐색 단계)
- 파트3 코드를 그대로 재실행해 동일 결과를 재현, 영업일수 보정 시 조합 신호 하나가 약해지는 점 확인
- 데모 웹을 실제 36개월 데이터로 구동하도록 개선하고, 아이엠뱅크 링크 오류 수정, 법인 유형 6개를 보여 주는 인사이트 화면 추가
- 요구불과 대출을 같은 기준으로 재분석하기 위한 사전 점검 — 새 식에서는 영업일수 보정 여부와 관계없이 결과가 같음을 확인

### 발표자료 작성

## 문제점 및 이슈

### 사전 추세로 인한 시간 순서 미확정

- 수출이 꺾이기 전에도 비슷한 차이(p 0.095)가 보여 "꺾인 뒤에 갈라졌다"는 인과적 시간 순서를 결과로 단정하기 어려움 — 발표 시 한계로 명시할 필요

### 처치 정의에 따라 결과가 달라지는 문제 지속

- rolling 기준은 수출을 멈춘 회사가 처치군에서 빠지는 구조적 문제가 있고, 전일 민감도 분석(수출 실적만으로 좁히면 p=0.597)과 함께 처치 정의 팀 확정이 여전히 필요

### 분석 결과 해석의 불안정성

- 대조군 추가·잔액 양수 관측 제한 등 분석 조건을 바꿀 때마다 업종별 해석과 유의성이 달라져(예: 1차 금속), 최종 발표에서 어떤 결과를 근거로 삼을지 선별 기준이 필요

### 산출물 확장에 따른 원래 연구질문과의 거리

- 분석 외에도 마케팅 월보 웹사이트, 상품 매칭, 용어 사전 등 산출물이 넓어지고 있어, 처음의 연구질문(수출 둔화 시 노출 법인의 여신행태 변화)에서 벗어나고 있지 않은지 점검이 필요

### 용어·검토 시점 문제로 인한 재작업

- 발표자료를 다 만든 뒤 용어를 바꾸느라 도식·표를 다시 그려야 했음 — 쓸 용어/쓰지 않을 용어를 먼저 정하고 시작하는 방식 필요
