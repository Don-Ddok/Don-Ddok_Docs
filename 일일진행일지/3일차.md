## 금일 작업 내용

### 성향점수매칭(PSM) 평가 오류 규명 및 매칭 표본 회귀 검증

- 기존에 "매칭 후에도 집단 간 격차가 해소되지 않는다"고 판단했던 결과가 평가 코드의 오류(복원추출로 같은 대조 법인이 여러 번 뽑히는데, 중복을 제거한 뒤 한 번씩만 계산)에서 비롯된 것임을 확인. 뽑힌 횟수를 반영해 재계산한 결과 매칭 기준 표준화 차이(SMD)가 0.01~0.06 수준으로 모두 기준을 통과함을 확인
- 짝지은 표본 위에서 "수출 충격에 노출·비노출 법인이 실제로 다르게 반응하는지"를 검정하는 회귀를 추가한 결과, 6개월 시차에서 수출이 10%p 하락할 때 비노출 법인은 대출을 줄이는 반면 노출 법인은 거의 유지하는 경향을 확인(약한 통계적 증거, p≈0.09)
- 대조군 구성 7가지, 이중강건추정, 환율 통제, 법인별 관측 시작월 통제 등 예상 가능한 반론을 모두 점검한 결과 방향성은 일관되게 유지됨을 확인 — 특정 대조군이나 우연한 반복 실행에서만 나온 결과가 아님을 검증

### 여신 세부 항목별 분석 및 업종별 매트릭스 실행

- 운전자금을 할인어음·기업구매자금 등 세부 항목 5개로 나누어 반응 순서를 검정한 결과 20개 검정 모두 뚜렷한 신호를 확인하지 못함 — 표본이 잘게 나뉘며 검정력이 부족해진 것으로, '효과 없음'과 '확정 불가'를 구분해 보고할 필요를 확인
- 업종별 유형(자금압박형·수요소멸형 등) 매트릭스를 실제 데이터로 실행한 결과, 업종 경기(호황·불황)와 대출 증감 방향이 서로 무관함(양쪽 모두 대출 증가 비율 18.3%로 동일)을 확인 — 기존에 언급된 '불황기 자금압박 기업 11%'는 통계적으로 의미 없는 숫자임을 확인

### 외부 데이터 오류 발견 및 정정

- 팀이 사용해 온 환율 데이터 파일이 한국은행 원자료와 60개월 중 52개월 불일치(최대 55.6원 차이)함을 발견하고, 한국은행 원자료로 다시 받아 교체

### 대외충격·경기선행성 관련 선행연구 9편 검토 및 계정 매핑

- 한국은행·한국금융연구원·통계청 등 선행연구 9편을 검토해 수출 충격이 기업 현금흐름을 거쳐 은행 계정으로 전달되는 경로와 연구모형 설계 근거를 정리하고, 은행 내부 계정을 수출거래 단계(원자재 확보~자금조달)에 대응시켜 계정별 선행·동행·후행 가설을 수립
- 관세청 대구·경북 국가별 수출자료로 2025년 관세 국면의 조기선적 가능성을 점검한 결과 그 영향은 미미했으며, 지역 수출 변동은 주로 대중 수출이 주도한다는 점을 확인

### 요구불예금 국면분해 방법론 설계

- 요구불예금의 국면 간 격차 분석과 3항 분해(구성·환경·수준효과) 방법론을 검토하고, 여러 달의 국면 정보를 집계해 데이터 공백에 강건한 결과를 내는 방식(A)과 대표 시점 간 정밀 비교가 가능하도록 법인 수·수출 YoY 등 데이터 기반 선별 기준을 세우는 방식(B)을 함께 설계
- 두 방식을 모두 적용해 교차 검증하는 프로세스를 마련해 데이터의 한계를 보완하고 분석 결과의 객관성을 높이기로 함

### 비상장 중소기업·재무정보 데이터셋 수집

- 프로젝트에 사용할 데이터셋을 수집하며 각 데이터가 분석에서 갖는 의미를 파악하고, 비상장 중소기업 데이터셋과 연도별 기업 재무정보를 수집

### 분석 코드 구조 재점검

- 분석 데이터를 검증하는 과정에서 코드 상의 숨은 오류를 발견하고 모델 구조를 재구성 — 데이터 전처리와 코드 기초 설계의 중요성을 재확인

### 이론적 근거 확충 및 회계·재무 지식 축적

- 관련 논문을 통해 연구모형의 이론적 근거를 확장하고, 분석에 필요한 회계·재무 지식을 체계적으로 축적

## 문제점 및 이슈

### PSM 평가 코드 오류로 매칭 결과를 잘못 판단했던 사례

- 복원추출로 여러 번 뽑힌 대조 법인을 중복 제거 후 한 번씩만 계산한 평가 코드의 오류로 '매칭이 균형을 이루지 못했다'고 오판했던 것을 확인 — 결과를 결과 자체로 받아들이기 전에 계산 과정을 먼저 점검해야 한다는 점을 재확인

### 여신 세부 항목·업종 매트릭스 분석에서 신호를 확인하지 못함

- 표본을 세부 항목·업종별로 나눌수록 검정력이 급격히 낮아져, 신호가 없는 것이 '효과가 없다'는 의미인지 '이 표본으로는 확인할 수 없다'는 의미인지 구분해 보고할 필요가 있음

### 매칭 없이는 결과가 재현되지 않음

- 매칭 표본에서는 확인된 경향이 매칭 없이 회귀 보정만 했을 때는 약해지고 유의성도 사라짐 — 비교 가능한 대조군을 확보하는 절차 자체가 결론의 핵심 전제라는 점이 다시 확인됨

### 외부 데이터(환율) 오류로 인한 팀 전체 영향 가능성

- 환율 데이터 파일의 오류를 발견해 정정했으나, 다른 파트에서 동일 파일을 사용했을 경우 결과에 영향이 있을 수 있어 팀 전체 확인이 필요함

### 요구불예금 국면분해 시 데이터 공백·시점 선정의 자의성 문제

- 국면을 나누어 비교하는 과정에서 특정 달을 임의로 선택하면 결과가 왜곡될 위험이 있어, 두 가지 접근을 병행하는 교차검증 구조로 대응하기로 함
