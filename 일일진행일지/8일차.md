## 금일 작업 내용

### 발표자료를 보고서로 재구성 (강사님 피드백 반영)

- 보고서에 가까운 44~48장 PPT를 피드백 수정 후 보고서로 사용 결정
발표용 PPT는 10~15분 + 질의응답 기준으로 줄이기 위해, 장 수를 14~15장으로 줄인 발표용 PPT를 제작 결정
- 흐름을 문제정의 → 데이터 → 방법론 → 핵심 결과 → 메커니즘 → 알아낸 것 → 활용 → 사업 가치 → 한계 → 요약 순서로 정리하고, 장마다 붙어 있던 "결론" 표기를 "요약·인사이트"로 변경
- 제목은 질문형으로 바꾸고 그 답이 하단 요약 박스에 나오도록 구성(예: "수출이 줄면 요구불은 몇 달 뒤 줄어드나?" → "6개월 뒤 약 3.6% 낮음")
- 장 수는 늘리지 않고 설명이 필요한 3장에만 도표 추가 — 방법론 개념도(노출·비노출 격차 β₃), 시차별 반응 그래프(h=6, −3.6%), 여섯 경로 추정치·95% 신뢰구간 도표와 판정표

### 문제정의 정리

- "왜 알고 싶은가 → 무엇을 알고 싶은가 → 그래서 무엇을 풀 것인가" 구조로 정리 — 기사(대구 기업 자금사정 악화, 대구 수출 장기 감소)에서 출발해 수출 충격이 노출 기업의 어느 계좌에 몇 개월 뒤 얼마나 전이되는지를 알고 싶었다는 팀 문제정의를 확정
- 기사 내용을 팀 수출 통계와 대조해 수치가 맞는지 확인
- 프로젝트를 찾게 된 과정을 정리 — 처음 질문(수출이 여신에 선행하는가)이 데이터 확인 과정에서 요구불예금 반응으로 바뀌고, 이후 상담 대상·시점을 정하는 활용 모델로 이어진 흐름

### 보고서 PPT 점검

- 쪽별 제목이 말하는 내용을 정리하다가 목차 번호 오류, 같은 내용이 두 번 들어간 쪽, 쪽 간 참조 번호 어긋남을 확인하고 수정 목록으로 정리
- 미리캔버스 공동 편집 문서의 슬라이드 제목을 질문형으로 바꾸는 작업 진행

### 비즈니스 모델 정리

- 돈독 비즈니스 모델을 "누가·누구를 위해·언제·무엇을·어떻게 고르고 우선순위를 매기는가"로 한 줄씩 정리한 표를 작성(트리거는 공식 수출통계 기준 둔화·성장 국면, 분류는 거래 유형 A~E, 우선순위는 요구불 규모 0.7 + 최근 3개월 감소폭 0.3)
- 수출이 줄거나 늘 때 은행이 미리 알면 어느 손익 항목에 영향이 있는지 검토 — 조달 비용(요구불 이탈 방어)은 결과로 뒷받침되고, 대손·외환 수수료는 확인되지 않아 가설로 구분
- 비즈니스 모델을 둔화뿐 아니라 성장 국면까지 양방향으로 확장하는 방안을 논의

### 성장 파일럿 설계서 및 문서 정리

- 성장 파일럿 전체 틀을 바탕으로 비즈니스 모델 확정에 필요한 확인 사항을 정리하고, 데이터 분석 파일럿 설계서 양식을 정해 채울 수 있는 항목을 먼저 채운 Word 문서를 작성
- 깃허브 문서 저장소에 4~6일차 일일 진행 일지, 데이터 명세서, 발표 PPT 재구성 제안·장별 원고(35장)·성장 파일럿 전체 틀을 반영

## 문제점 및 이슈

### 인과로 읽히는 표현과 현재 결과의 범위 차이

- 현재 결과로 확정한 것은 요구불예금의 연관성(수출 10%p 하락 시 6개월 뒤 약 −3.6%)이며, 인과 효과나 상담의 개입 효과까지는 확인하지 못함
- 비즈니스 모델 정리표의 "관계유지 효과가 이미 관측됐다" 같은 문장은 인과로 읽힐 수 있어 "관찰된 연관" 수준으로 표현 조정 필요

### 비유의 결과의 해석 방식

- 유의하지 않은 경로(거치식·운전자금·입금·외환 실적 연결)를 "효과 없음"으로 읽히지 않게 해야 함 — 신뢰구간과 최소검출효과(MDE)로 "어디까지 확인할 수 있었는지"를 보여 주는 방식이 필요

### 수출 노출도 정의가 충격 이후 정보를 쓰는 문제

- 현재 외환 노출은 36개월 중 수출·수입 실적이 1회 이상 있는 법인으로 정의해 충격 이후 정보가 섞여 있음 — 이미 2023년 기준 노출 정의로 바꾸면 효과가 −0.55%(p 0.801, 검정력 35%)로 약해지는 한계를 확인한 상태라, 충격 이전 정보만으로 정의해도 핵심 결과가 유지되는지 점검 필요

### 결측·0값 처리 기준 미정

- 계좌 미보유, 실제 잔액 0, 기록 누락이 한 값(0)으로 섞여 있음 — 거치식·적립식은 0 이하 관측이 37.6%·40.4%로 높아, 세 경우를 먼저 구분한 뒤 허들(hurdle) 모형 검토 필요

### 문서 간 수치·단위 표기 대조 필요

- 보고서 PPT의 목차·쪽 참조 어긋남과 함께, 법인 수·노출 법인 수·금액 단위(원/백만원) 표기가 문서마다 달라 보이는 부분은 최종 보고서 값을 기준으로 대조 후 확정 필요

## 피드백 정리

### 강사님 피드백 (발표자료)

- PPT가 너무 복잡하고 연구 보고서에 가까움 — 장 수를 줄이고 발표용으로 단순하게
- 문제정의에 "왜 알고 싶은가, 그걸로 무엇을 풀 것인가"가 없음
- 제목은 훅처럼 좋지만 왜 그 제목인지가 내용에 없음
- "결론" 표기 부적절 — "요약" 또는 "인사이트(알아낸 것)"로 표시, 과정에 비해 알아낸 것이 작아 보이니 요약 문구 고민
- 흐름은 과정(빠르게) → 우리가 알아낸 것 → 그래서 이렇게 활용할 수 있다, 과정과 하단 요약 모두 쓰임이 있어야 함
- 발표는 10~15분으로 잡고 이후 질의응답 시간 확보

### 추가 피드백 (분석·활용 설명 방식)

- 현재 데이터로 인과까지 설명하기보다 "요구불예금에서 일부 연관성이 관찰됐다" 정도로 정리하고, 비유의 결과도 효과 없음으로 결론짓지 말고 신뢰구간과 최소검출효과로 확인한 범위를 보여 줄 것
- 결측과 0값은 계좌 미보유 · 실제 잔액 0 · 기록 누락 구분을 먼저 하고, 그 다음 허들 모형을 검토하는 순서로 진행
- 남은 기간에는 새로운 분석을 늘리기보다 충격 이전 정보로 수출 노출도를 정의해 핵심 결과가 유지되는지 확인
- 상품 매칭은 효과가 검증된 추천 모델이 아니라 상담 후보를 제안하는 도구로 설명하면 분석 결과와 자연스럽게 연결됨
