`내지_배경.png`는 흰 바탕에 오른쪽 위 옅은 민트 원·점 무늬, 아래쪽에 돈독 로고와 프로젝트명·기간이 들어간 본문 슬라이드 배경입니다. `내지_배치예시.png`는 제목·요약·본문·페이지 번호 자리를 표시한 예시이고, 원본은 `내지_원본.html`입니다.

## 고치는 방법

- `.excalidraw`: [excalidraw.com](https://excalidraw.com)에서 메뉴 → 열기로 불러와 고친 뒤 PNG로 내보냅니다.
- `.html`: 브라우저에서 열어 확인하고 고칩니다. 주소 끝에 `?mode=bg`(배경만), `?mode=logo`·`?mode=logo,dark`(로고만, 연두판은 `?mode=logo`·`?mode=logo,ondark`), 내지는 `?mode=show-guide`(배치 안내)를 붙이면 판이 바뀝니다. 3840×2160으로 캡처해서 씁니다.
- 캡처하기 전에 Pretendard 글꼴이 굵기별로 다 불러와졌는지 확인합니다. 안 그러면 대체 글꼴로 찍힙니다.
