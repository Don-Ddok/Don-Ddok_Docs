# 파트 3 — 여신·업종 분석

담당: 이성진, 전유환 · 기간: 2026-09-22 ~ 09-27

수출 경기가 꺾일 때 대구·경북의 수출입 법인과 비슷한 조건의 비노출 법인이 운전자금 대출을 다르게 움직이는지 비교한 분석입니다.

## 한 줄 결론

비슷한 회사끼리 짝지어 비교하면, 수출이 꺾일 때 **비노출 회사는 운전자금 대출을 줄이고 수출입 회사는 유지하는 경향**이 보입니다(6개월, β₃ = −0.231, 법인·월 이중 클러스터 p = 0.094). 방향은 24개 모형 모두 같지만 **통계적으로는 약한 증거**입니다(검정력 39%).
