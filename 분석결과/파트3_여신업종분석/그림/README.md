## 읽는 법 (색과 표시)

| 표시 | 뜻 |
|---|---|
| 초록 | 완료 · 유지 · 설명되지 않음(반론을 통과) |
| 노랑 | 약한 증거 (p 0.05~0.10) |
| 파랑 | 부분 지지 |
| 회색 | 근거 없음 (p ≥ 0.10) |
| 주황 | 주의 · 한계 (사전 추세 의심, 검정력 부족 등) |

> 인과가 아니라 관련성, 조기경보가 아니라 참고 신호로 읽습니다. 수출이 꺾이기 전에도 같은 차이가 보여(그림 13) "꺾인 뒤에 갈라졌다"는 시간 순서는 확정할 수 없습니다.
