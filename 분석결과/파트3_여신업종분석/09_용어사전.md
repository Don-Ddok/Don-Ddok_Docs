## 경기와 시점

| 용어 | 뜻 | 쉬운 비유·예시 | 나오는 곳 |
|---|---|---|---|
| **수출 전년비**<br>(다른 이름: 전년동월비, YoY, 수출 증감률) | 이번 달 수출액이 1년 전 같은 달보다 몇 % 늘었거나 줄었는지입니다. 대구·경북 월별 수출은 관세청 통계(한국무역협회 K-stat)를 씁니다. | 작년 9월과 올해 9월을 비교하면 계절 차이는 대부분 사라집니다. |  |
| **영업일수**<br>(다른 이름: 달력, 달력 착시) | 그 달에 주말·공휴일을 뺀 일하는 날의 수입니다. 설·추석이 어느 달에 들어가느냐에 따라 같은 달도 해마다 며칠씩 달라져, 수출 전년비가 경기와 무관하게 흔들립니다. | 작년 9월에 추석이 있었고 올해는 10월에 있으면, 올해 9월 수출은 경기와 상관없이 "늘어" 보입니다. |  |
| **보정 수출 전년비**<br>(다른 이름: 달력 보정, 보정YoY) | 수출 전년비에서 영업일수 차이 몫을 걷어낸 값입니다. 이번 달 추천의 단계는 이 값으로 정합니다. |  | 이번 달 추천, 팀 인사이트(지역 수출) |
| **둔화 단계**<br>(다른 이름: 평시, 관찰, 적기, 정점·유지, 장기둔화, 단계) | 지역 수출이 꺾인 뒤 몇 달이 지났는지로 나눈 다섯 단계입니다. 평시(둔화 신호 없음) → 관찰(시작 후 0~2개월) → 적기(3~6개월) → 정점·유지(7~12개월) → 장기둔화(13개월 이후). 개월 수 구간은 공개 데이터에서 확인한 값입니다. |  | 이번 달 추천, 홈 |
| **둔화 시작(T0) · 경과(k)**<br>(다른 이름: T0, k, 둔화 시작)<br>(팀 확인 중) | T0는 팀 매칭 모델이 보정 수출 전년비로 판단한 둔화 시작 달, k는 그때부터 지난 개월 수입니다. 데이터 첫 달(2023년 1월)에 이미 둔화 중이면 "이전"으로 표시합니다. |  | 이번 달 추천 머리 줄 |
| **광공업생산지수**<br>(다른 이름: 생산지수) | 공장이 얼마나 만들었는지를 2020년=100으로 나타낸 통계청(KOSIS) 지수입니다. 파트 3은 제조업 업종별 경기를 볼 때 씁니다. |  | 여신 분석(업종 경기) |
| **기준금리 · 원/달러 환율** | 한국은행 ECOS 원자료입니다. 수출 둔화가 아니라 금리 인하나 환율 때문에 대출이 움직였을 가능성을 걸러 내는 통제변수로 씁니다. |  | 여신 분석 8-1(환율), 8-8(기준금리) |

## 분석 방법

| 용어 | 뜻 | 쉬운 비유·예시 | 나오는 곳 |
|---|---|---|---|
| **짝짓기 (성향점수매칭)**<br>(다른 이름: 매칭, PSM, 1:3 매칭) | 외환노출 고객 한 곳마다 업종·규모 등 조건이 비슷한 비노출 고객 세 곳을 골라 짝을 지은 뒤 비교합니다. | 키·나이가 비슷한 사람끼리 비교해야 약의 효과를 볼 수 있는 것과 같습니다. |  |
| **β₃ (반응 차이)**<br>(다른 이름: 베타3, β3, 교호항) | 수출이 줄 때 외환노출 고객의 대출 변화가 짝지은 비노출 고객과 얼마나 다른지를 나타내는 숫자입니다. 파트 3 주 결과는 −0.231로, 수출이 10%p 떨어질 때 두 집단의 6개월 운전자금 변화가 약 2.3%p 벌어진다는 뜻입니다(비노출은 줄이고 노출은 유지). |  | 여신 분석 22장 |
| **6개월 창 (h)**<br>(다른 이름: h, h=6, 시차) | 충격이 있은 달부터 몇 개월 뒤까지의 변화를 보는지입니다. 파트 3은 결과를 보기 전에 6개월로 고정했습니다. |  |  |
| **이중 클러스터**<br>(다른 이름: 법인·월 이중 클러스터, 군집 표준오차) | 같은 회사의 여러 달, 같은 달의 여러 회사가 서로 닮은 점을 감안해 불확실성을 넓게 잡는 계산법입니다. 결과를 덜 낙관적으로 보게 합니다. |  |  |
| **사전 추세**<br>(다른 이름: 평행 추세) | 수출이 꺾이기 전에도 두 집단이 이미 다르게 움직이고 있었는지 확인하는 점검입니다. 파트 3에서는 꺾이기 전 6개월에도 같은 모양의 차이가 보여(p 0.095) "꺾인 뒤에 갈라졌다"는 순서를 확정하지 못했습니다. |  | 여신 분석 8-7 |
| **Holm 보정**<br>(다른 이름: 다중검정 보정) | 질문을 여러 개 던지면 우연히 하나쯤 맞을 확률이 커지므로, 질문 수만큼 기준을 엄격하게 바꾸는 방법입니다. 9단계 질문 4개는 보정 후 모두 근거 없음이었습니다. |  | 여신 분석 9단계 |
| **검정력**<br>(다른 이름: 최소검출효과) | 효과가 실제로 있을 때 그것을 잡아낼 확률입니다. 파트 3 추정치 크기에서는 39%라, 유의하지 않은 결과를 "효과 없음"이 아니라 "확정 불가"로 읽습니다. |  |  |
| **위약 검정 · 포착률**<br>(다른 이름: 위약, 포착률, 무작위 대조) | 신호가 아무 달에나 무작위로 켜졌을 때와 비교해, 실제 신호가 수출 둔화 달을 더 잘 잡는지 보는 점검입니다. 신호 ②는 달력 보정 후 포착률 51.1%로 무작위(53.0%)보다 낮아 기각됐습니다. |  | 신호 규칙 점검, 팀 인사이트(가설 검증) |
| **사후 보조** | 결과를 본 뒤에 추가로 돌린 분석입니다. 판정에는 쓰지 않고 해석을 돕는 참고로만 적습니다(예: 8-9 달력월 더미). |  |  |

## 판정과 표시

| 용어 | 뜻 | 쉬운 비유·예시 | 나오는 곳 |
|---|---|---|---|
| **p값과 판정 등급**<br>(다른 이름: p, 유의, 약한 증거, 근거 없음) | 우연만으로 이 정도 차이가 나올 가능성입니다. 파트 3은 미리 정한 기준으로 p<0.05 유의, 0.05~0.10 약한 증거, 0.10 이상 근거 없음으로 판정합니다. |  |  |
| **지지 · 기각 · 보류** | 팀 가설 재검증 결과입니다. 지지는 재검정에서도 유의, 기각은 재검정에서 사라짐, 보류는 부호는 맞지만 위약 검정 등을 통과하지 못한 탐색적 결과입니다. |  | 팀 인사이트(검증된 가설) |
| **관련성 (인과 아님)**<br>(다른 이름: 관련성, 인과) | 두 값이 함께 움직인다는 뜻이지, 하나가 다른 하나를 일으켰다는 뜻이 아닙니다. 이 사이트의 모든 결과는 관련성으로 읽습니다. |  |  |
| **참고 신호** | 위험 판정이나 예측이 아니라, 누구에게 먼저 연락할지 고를 때 참고하는 표시입니다. |  |  |
| **가상 데이터 (시연용)**<br>(다른 이름: 시연용, 가상 고객) | 신호 월보의 고객 80곳과 계좌 금액은 규칙이 작동하는 모습을 보여 주려고 만든 가상 값입니다. 연구 방향을 심어 만들어 규칙이 실제보다 잘 걸리는 것처럼 보입니다. |  | 신호 월보 |

> 수치는 파트 3 문서와 팀 매칭 모델 데이터에서 확인한 값입니다. 결과는 인과가 아니라 관련성으로 읽습니다.
