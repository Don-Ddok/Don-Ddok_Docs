돈독(Don-Ddok) · 파트 3 여신·업종 분석 · 이성진, 전유환 · 설계 확정 2026-09-23 (실행 전) · **실행 완료 2026-09-28**

1~8단계에서 아직 답하지 않은 질문만 다루는 문서다. 주 결과와 1~8단계 근거는 [01_작업순서와_결과.md](01_작업순서와_결과.md), 한계 정리는 [02_한계와_해결방안.md](02_한계와_해결방안.md)에 있다. 각 분석의 결과는 [08_달력통제_이후_결과.md](08_달력통제_이후_결과.md) 2절에 기록한다.

**결과 요약(2026-09-28)**: 9-1~9-4 전부 실행. **Holm 보정 후 4개 모두 "근거 없음"**(보정 전 p 0.070~0.695 → 보정 후 0.278~1.0). 9-3·9-4(표본을 좁히는 검정)는 효과 크기가 기준의 35~36%로 줄었고, 9-2(노출 강도)는 기대와 반대 방향(강도가 낮을수록 반응이 큼)이 나왔다. 주 결과(3-3, β₃=−0.231, p=0.094)는 9단계와 별개라 그대로 유지한다.

## 1. 설계 (실행 전 확정 — 실행 후 바꾸지 않음)

**원칙**
- 이미 한 분석을 방법만 바꿔 다시 돌리지 않는다(p-해킹 방지). 9단계는 **새 질문**만 다룬다
- 주 결과(3-3: h=6·매칭 1:3·이중 클러스터, β₃=−0.231)는 바꾸지 않는다. 9단계 결과는 "추가 분석" 표로 따로 보고한다
- 모든 분석의 공통 조건: 종속변수 `대출증감률_h6`, 법인 FE + 연도 더미, 법인·월 이중 클러스터(자유도 = 적은 쪽 클러스터 − 1), 매칭은 3-2와 같은 절차(`common.psm_match`)
- 결과가 좋든 나쁘든 그대로 보고한다. 아래 설계는 실행 후 바꾸지 않는다

**검정 계획 — 주 검정 4개, Holm 보정**

| # | 질문 | 관련 가설 | 주 검정 (기대 부호) | 보조로만 보고 |
|---|---|---|---|---|
| 9-1 | 차이가 수출 **하락** 국면에서 생기나 | 연구질문("둔화될 때"), H4 | β₃⁻ = 수출YoY⁻ × 노출 (음수) | β₃⁺, 비대칭 검정(β₃⁻ = β₃⁺) |
| 9-2 | 더 자주 수출입하는 회사일수록 더 크게 반응하나(용량-반응) | H2, 열린 이슈 4 | γ = 수출YoY × 노출 강도 (음수) | 이중강건 버전 |
| 9-3 | 수입만 하는 회사를 빼고 **수출 회사만** 처치로 봐도 같은가 | 기준 문서 강건성 항목 | β₃ (음수) | — |
| 9-4 | 36개월 모두 관측된 **균형 패널**에서도 같은가 | 기준 문서 강건성 항목 | β₃ (음수) | — |

- 주 검정 4개의 이중 클러스터 p를 Holm 보정하고, **판정은 Holm 보정 p로** 한다: <0.05 "유의" / 0.05~0.10 "약한 증거" / ≥0.10 "근거 없음"
- 9-3·9-4는 주 결과의 강건성 점검이기도 하므로 8단계와 같은 기준(부호 같고 크기가 −0.231의 절반 이상 → "유지")도 함께 적는다
- 보조 결과(β₃⁺, 비대칭 검정, 이중강건 버전)는 보정 없이 참고로만 보고하고 판정에 쓰지 않는다

**9-1 하락·상승 국면 분리**

| 항목 | 확정 |
|---|---|
| 충격 분리 | 수출YoY⁻ = min(수출YoY, 0), 수출YoY⁺ = max(수출YoY, 0) |
| 식 | 대출증감률 = 법인 FE + 연도 + β₁⁻·수출YoY⁻ + β₁⁺·수출YoY⁺ + **β₃⁻·수출YoY⁻×노출** + β₃⁺·수출YoY⁺×노출 |
| 표본 | 3-2 매칭 표본(1:3 가중) |
| 해석 | β₃⁻ < 0: 수출이 떨어질수록 노출 회사가 대출을 상대적으로 더 유지. 비대칭 검정은 이중 클러스터 분산 전체로 β₃⁻ − β₃⁺ 검정 |
| 미리 적어 둘 한계 | 2023~2025년 수출이 전년보다 줄어든 달이 경북 26/36, 대구 22/36 → 상승 국면 관측(10·14개월)이 적어 β₃⁺는 부정확할 수 있음 |

**9-2 노출 강도 (연속형)**

| 항목 | 확정 |
|---|---|
| 노출 강도 | 회사가 관측된 달 중 외환 수출 또는 수입 실적이 있는 달의 비율(0~1). 비노출 회사는 0. 금액이 아니라 빈도라 단위 문제(백만달러 vs 백만원)와 결과 변수(대출) 오염이 없음 |
| 식 | 3-3 식 + **γ·수출YoY×강도** (강도는 노출 회사 평균으로 중심화) → β₃는 "평균 강도 노출 회사"의 반응, γ는 강도가 높을수록 추가되는 반응 |
| 표본 | 3-2 매칭 표본(1:3 가중) |
| 보조 | 4-3 이중강건 교호항 5개 추가 버전 |
| 미리 적어 둘 한계 | 강도는 36개월 전체로 계산하므로 충격 이후 수출 활동도 반영된다(충격이 수출 빈도를 바꿨다면 섞임). 회사 단위 노출 강도라 기준 문서 H3(**업종** 수출지향도)와는 다르다 — H3는 팀 담당 확인 후 결정 |

**9-3 수출 회사만 처치**

| 항목 | 확정 |
|---|---|
| 표본 | 운전자금 보유 회사 중 **수입만 한 회사 제외**(처치에도 대조에도 넣지 않음) |
| 처치 | 수출노출(외환 수출실적 1회 이상) |
| 절차 | `common.psm_match`로 다시 매칭(같은 공변량, 1:3 복원) → 균형 확인 → 3-3 식 |

**9-4 균형 패널**

| 항목 | 확정 |
|---|---|
| 표본 | 운전자금 보유 회사 중 36개월 모두 관측된 회사 |
| 절차 | `common.psm_match`로 다시 매칭 → 균형 확인 → 3-3 식 |
| 미리 적어 둘 한계 | 대구·경북 균형 패널 2,692곳 중 외환노출 약 197곳 → 노출 회사가 적어 부정확할 수 있음 |

**9-5 업종별 수출 충격 — 보류 (Holm 대상 아님)**
데이터(K-stat 지역별 품목별 수출, HSK 2단위, 대구·경북, 2022.01~2025.12 월별)를 받고 HS–KSIC 매핑을 마친 뒤, **실행 전에 별도로 설계를 고정**한다. 받지 않으면 하지 않는다.

**실행 순서**: 9-1 → 9-3 → 9-4 → 9-2 (조각마다 결과 확인). 9-2는 H3 담당 확인과 무관하게 회사 단위(H2)라 진행 가능.
