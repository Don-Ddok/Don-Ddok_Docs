## 1. 여러 시차 결합검정 (Joint Test across Horizons)

### 1-1. β₃ 계수의 부호가 의미하는 것

β₃는 DID(이중차분법) 회귀식의 ‘노출법인 × 충격변수’ 교호작용항 계수다. 같은 크기의 수출 충격이 왔을 때, 노출법인이 비노출법인보다 대출을 얼마나 더/덜 조정했는지를 나타낸다.

- β₃ < 0 (음수): 노출법인이 비노출법인보다 대출을 더 많이 위축시켰다는 뜻
- β₃ > 0 (양수): 노출법인이 오히려 대출을 덜 줄이거나 늘렸다는 뜻

현재 확보된 값: β₃ = −0.231 (p = 0.094, 5% 유의수준 미달).

“여러 시차의 부호가 일관되게 음수”라는 말은, h(시차)를 h=3, 6, 9, 12로 바꿔가며 추정한 β₃(h) 값들이 모두 같은 방향(−)으로 나온다는 뜻이다. 개별적으로 유의하지 않아도, 방향이 우연이 아니라 계속 같은 쪽으로 나온다는 사실 자체가 “노이즈가 아니라 진짜 효과일 가능성”을 시사하는 정황증거가 된다.

### 1-2. 결합검정이 검정력을 높이는 원리

검정력(statistical power): 진짜로 효과가 존재할 때, 검정이 그 효과를 ‘있다’고 올바르게 탐지해낼 확률.

개별 h 하나짜리 검정은 표본이 작아(2,522개 회귀표본) 검정력이 약하다(약 39%). 반면 h=3,6,9,12 넷을 동시에 ‘전체적으로 0이 아니다’라고 하나의 검정으로 합치면, 각 신호에 섞인 노이즈는 상쇄되고 공통된 신호(진짜 효과)는 누적되어 검정력이 올라간다.

독립적인 네 추정치를 가중평균하면 결합 추정치의 표준오차(SE)는 대략 다음과 같이 줄어들 수 있다:

SE(결합) ≈ SE / √4 = SE / 2

(완전 독립을 가정한 상한선이며, 실제로는 h들끼리 상관되어 있어 이만큼 줄지는 않는다. 방향은 동일하다.)

### 1-3. Wald 검정 / F 검정

t-검정이 계수 하나가 0인지를 보는 것이라면, Wald/F 검정은 여러 계수가 동시에 0인지를 보는 확장판이다.

**Wald 통계량:**

W = (Rβ̂ − r)′ [R V̂ R′]⁻¹ (Rβ̂ − r)

- R: 어떤 제약을 검정할지 지정하는 행렬 (예: β₃(3)=0, β₃(6)=0, β₃(9)=0, β₃(12)=0)
- r: 제약이 맞다면 되어야 할 값 (여기선 전부 0)
- V̂: 계수들의 분산-공분산 행렬 추정치
- 표본이 크면 W ~ χ²(q), q = 제약 개수(여기선 4)

F 검정: Wald와 같은 아이디어를 유한표본에 맞게 보정한 버전. F = W / q, F(q, n−k) 분포와 비교.

### 1-4. 계산 예시

가상 예시로, β₃(3) = −0.10 (SE=0.06), β₃(6) = −0.231 (SE=0.14), 두 계수의 공분산 = 0(독립 가정):

W = (−0.10)²/0.06² + (−0.231)²/0.14² = 2.78 + 2.72 = 5.50

자유도 2인 카이제곱분포의 5% 임계값 ≈ 5.99. 이 가상 예시에서는 5.50 < 5.99로 아직 기각은 못 하지만, 개별 t-검정(각각 t=−1.67, −1.65로 개별 유의 안 됨)보다 유의수준에 훨씬 가까워진다 — 결합의 효과를 숫자로 보여주는 예시다.

### 1-5. 부호 뒤집힘 리스크와 해결책

표준 Wald/F 검정(모든 β₃(h)=0을 동시에 검정)은 제곱합 구조이므로 부호에 무관하게 안전하게 작동한다. 문제는 ‘단순 평균/합’으로 결합하는 방향성 검정을 쓸 때 생긴다 — h별로 부호가 실제로 뒤집히면(예: 초기엔 유동성 확보용 대출 증가(+), 후기엔 신용축소(−)) 평균이 서로 상쇄되어 실제 효과가 있어도 ‘없다’고 잘못 결론 내릴 수 있다.

**해결 방법:**

- ① 방향 무관 Wald/F를 기본 검정으로 사용 (부호 뒤집혀도 안전)
- ② 결합검정 전에 h=−3~12 계수경로 그래프(coefficient path plot)로 부호를 먼저 육안 확인
- ③ 실제로 부호가 뒤집힌다면, 국면 구분(state-dependent) 모형으로 전환 — “전체 평균 효과” 대신 “초기/후기” 등 국면별로 β₃를 따로 추정 (참고: Ramey & Zubairy 2018 계열, 팀 교재 외 내용)

## 2. 신뢰도·타당도·검정력 개념 구분

### 2-1. 세 개념 정의

| 개념 | 정의 |
|---|---|
| 신뢰도 (reliability) | 같은 것을 반복 측정했을 때 얼마나 일관된 값이 나오는가 (정확함이 아니라 일관성) |
| 타당도 (validity) | 재려고 하는 개념을 실제로 제대로 재고 있는가 |
| 검정력 (statistical power) | 진짜 효과가 있을 때 그것을 올바르게 탐지해낼 확률 |

핵심: 검정력이 높다 ≠ 신뢰도·타당도가 높다. 표본만 늘리면 검정력은 오르지만, 매칭이 부실하면(타당도 낮음) 여전히 틀린 결론을 ‘자신 있게’ 내릴 위험이 커진다.

### 2-2. 다트판 비유 (책에 없는 내용)

- 신뢰도가 높다 = 화살이 한곳에 몰려서 박힌다 (일관성)
- 타당도가 높다 = 화살이 과녁 중심(진짜 목표)에 박힌다 (정확성)
- 신뢰도는 타당도의 필요조건이지 충분조건이 아니다

검정력은 ‘화살을 몇 발 쐈고 과녁이 얼마나 큰가’에 가깝다 — 조준이 애초에 틀려도(타당도 문제), 화살을 충분히 많이 쏘면(표본 확대) ‘엉뚱한 과녁에’ 명중했다고 높은 확률로 판정할 수 있다. 검정력이 높다고 타당한 걸 재고 있다는 보장은 없다.

### 2-3. 실제 위험 시나리오

PSM 매칭이 부실해 노출/비노출 법인이 수출 여부가 아닌 다른 이유(규모·업력 등 교란변수)로 대출행태가 다르다면, β₃는 ‘수출충격 효과’가 아니라 ‘교란변수 효과’를 재는 것 — 타당도 낮음. 이 상태에서 표본만 늘리면 β₃가 강하게 유의해질 수 있으나(검정력↑), 여전히 잘못된 결론을 확신 있게 내리는 위험이 커진다.

## 3. 신뢰도·타당도·검정력을 개별적으로 높이는 방법

### 3-1. 신뢰도

- 데이터 정제 (이상치·입력오류·중복 제거)
- 표준화된 계산 절차 (모든 법인에 동일한 공식 적용)
- 정확한 표준오차 추정 (법인×월 이중클러스터 SE)

### 3-2. 타당도

- PSM 매칭품질 검증 (SMD, AUC)
- 평행추세 검정 (parallel trends assumption)
- 이중강건추정 (doubly robust)
- 강건성 검정 (처치정의·모형을 바꿔도 결론이 유지되는지)
- 대안설명 배제 (외부데이터로 신용긴축 vs 수요감소 등 경쟁가설 검증)

### 3-3. 검정력

- 표본 크기 확대 (현재 976개 매칭으로 한계 있음)
- 여러 h 결합검정으로 정보 누적
- 공변량 추가로 잔차분산 축소
- 효과가 큰 하위집단(예: 전자부품)에 집중

## 4. 결합검정·다중클러스터가 신뢰도·타당도를 낮추는가?

| 방법 | 신뢰도 | 타당도 |
|---|---|---|
| 이중(다중)클러스터 SE | 낮추지 않음 — 과대평가된 신뢰도를 정직하게 교정 | 거의 무관 (식별전략을 건드리지 않음) |
| 여러 시차 결합검정 (Wald/F) | 낮추지 않음 — 일관된 신호 확인 시 오히려 강화 | 검정 자체는 안전, 해석 시 과잉일반화 주의 필요 |

이중클러스터 SE는 β₃(점추정치)를 전혀 건드리지 않고, SE만 더 정확하게(대개 더 크게) 계산한다. SE가 커져 유의성이 떨어질 수 있으나, 이는 ‘신뢰도 저하’가 아니라 ‘원래부터 있던 불확실성을 정직하게 드러낸 것’이다.

결합검정의 진짜 위험은 해석이다. 예컨대 h=6만 강하게 유의하고 나머지는 0에 가까운데 결합검정만 유의하다고 보고하면, 실제로는 ‘일시적 스파이크’인데 ‘지속적 효과’로 오독될 수 있다. 해결책: 결합검정 p-value와 h별 개별 계수 그래프(신뢰구간 포함)를 항상 세트로 제시할 것.

참고: 이는 ‘다중검정 보정(여러 번 검정 시 우연히 하나 걸릴 확률 증가)’ 문제와 다르다. Wald/F 결합검정은 오히려 그 문제(h별로 따로 검정해서 유의한 것 하나만 골라 보고하는 오류)를 막기 위한 올바른 도구다.

## 5. 실행 순서 및 준비사항

### 5-1. 0단계 — 착수 전 팀 합의

- “통계적 유의성(p<0.05) 확보”가 최우선 목표라는 점을 재확인, 남은 기간(4~7일) 내 어디까지를 최소 산출물로 할지 합의
- 기존 PSM 코드·매칭 결과 파일(976개 매칭) 위치 확인

### 5-2. 1단계 — PSM 매칭품질 재확인 (타당도)

- PSM에 사용한 공변량 목록 확보 (법인규모·업종·지역·고객등급·업력 등)
- 매칭 전/후 SMD 표 계산 (기준: SMD < 0.1)
- 성향점수 모형 AUC 계산 (매칭 후 0.5에 가까워지는지 확인)
- 매칭 전/후 성향점수 분포 히스토그램

산출물: SMD표 + AUC 수치(전/후) + 분포그림

### 5-3. 2단계 — 공변량 추가 (신뢰도+검정력)

- 현재 회귀식의 기존 통제변수 목록 정리
- 은행데이터 공급목록(2023.01~2025.12)에서 추가 가능한 컬럼 스크리닝 (계절성 더미, 법인 고정효과, 신용등급 변화 등)
- 추가 후보 변수 간 다중공선성(VIF) 체크
- 회귀 재실행 후 잔차 표준오차 전/후 비교

### 5-4. 3단계 — 결합검정 + 계수경로 그래프 (검정력+해석타당도)

- h=3,6,9,12별 β₃, SE 정리 (없으면 재추정)
- h들 간 공분산 추정 (SUR / 시스템GMM 또는 부트스트랩)
- Wald/F 통계량 계산 코드 작성
- 계수경로 그래프 작성 (부호 일관성 사전 확인)
- 필요 시 2-way wild cluster bootstrap 적용 (5-6절 참고)

### 5-5. 4단계 — 처치정의 강건성 검정 (타당도+신뢰도)

- 처치변수 3버전 정리: 외환노출 더미 / 수출노출 더미 / 노출강도(연속형)
- 연속형 노출강도는 중간 분석 보고서에서 이미 비유의(p=0.1235)로 확인됨 — 실패 사례로 인용
- 더미 방식 두 버전으로 매칭·회귀 재실행 후 β₃ 비교표 작성

### 5-6. 2-way Wild Cluster Bootstrap 상세

배경: 법인×월 이중클러스터 SE는 클러스터 수가 충분히 많을 때(대략 30~50개 이상) 잘 작동한다. 매칭 후 표본이 976개로 줄어 클러스터 수가 적어지면(특히 노출법인 쪽), 일반 클러스터 SE 공식이 왜곡될 수 있어 wild cluster bootstrap을 대안으로 검토한다.

Wild bootstrap 개념: 관측치를 다시 뽑는 대신, 각 클러스터의 잔차에 무작위 부호(±1, Rademacher 분포)를 곱해 가상의 재표본을 다수 생성하고, 그 분포에서 직접 p-value를 구하는 방법.

2-way 확장: 법인 부호 v_i와 월 부호 w_t를 각각 독립적으로 뽑아 곱한다.

e_it(b) = e_it × v_i(b) × w_t(b)

**알고리즘:**

- ① 원래 회귀의 잔차·t값 계산
- ② 귀무가설(β₃=0)을 강제한 제약모형의 잔차 계산
- ③ B회(예: 9999회) 반복: 법인별·월별 부호를 각각 뽑아 곱해 잔차에 적용, 매번 새 t값 계산
- ④ B개의 t값 분포에서 원래 t값의 위치로 p-value 산출: p = (1/B)Σ 1[|t(b)| ≥ |t원래|]

클러스터 수가 적을 때(대략 12개 미만)는 Rademacher 대신 Webb(2014) 6점 분포(±1, ±√(1/2), ±√(3/2))를 사용해 더 다양한 조합을 생성한다.

구현 시 유의사항: 팀 “문제해결” 문서의 Python wildboottest 코드는 cluster 인자가 하나뿐이라 1-way(법인만)용으로 보인다. 2-way 지원 여부를 사전에 확인하거나, R의 fwildclusterboot 패키지(2-way 명시 지원) 사용을 검토할 것.
