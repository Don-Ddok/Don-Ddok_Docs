# β₁+β₃ 합 검정 — 사전등록 (2026-09-29, 결과 확인 전 작성)

피드백 "β₁+β₃의 통계 검정 확인" 대응. 아래 기준은 결과를 보기 전에 정했고, 결과를 본 뒤 바꾸지 않는다.

## 배경
- 매칭 모델의 근거 문구 "β₁+β₃: 수출 10%p 하락당 6개월 4.2%, 12개월 5.2%, h=3부터 확실"은 팀 코드 `Downloads\beta1_common.py`의 결과다.
- 그 코드는 β₁+β₃의 t값(t13)만 계산하고, p값·여러 시차 보정은 하지 않는다. 의존 파일(special2.py, workdays)이 없어 그대로 재실행할 수 없다.
- 그래서 같은 식을 복사본(`code\beta_sum_test.py`)으로 다시 세워 검정한다. 원본 파일은 수정하지 않는다.

## 식 (beta1_common.py와 같은 구조)
ln(Y_{i,t+h}+1) − ln(Y_{i,t−1}+1) = α_i + δ_m + β₁·S_{r,t} + β₃·(S_{r,t}×D_i) + ε
- Y: 요구불예금잔액. h마다 종속변수를 1%/99% 윈저라이즈 (YoY.ipynb와 같음).
- S: 지역 수출 YoY ÷ 10 → 계수는 "수출 YoY 10%p당 누적 로그 변화".
- D: 외환노출 (36개월 중 수출·수입 실적 1회 이상, df_ready의 exposed).
- α_i: 법인 고정효과. δ_m: 달력월(1~12월) 더미. 연월 고정효과는 β₁을 흡수하므로 쓰지 않는다 (원본과 같음).
- 표본: df_ready.csv의 대구·경북 법인×월, 2023-01~2025-12.
- 표준오차: 법인·월 이중 군집 (lib.twoway_vcov). p값은 t(G월−1).

## 사양
- **주 사양 (판정용): 보정 충격.** S = 트리거가 쓰는 보정 수출 YoY (trigger_stages.csv의 보정YoY). 단계 판정과 같은 충격이다.
- **보조 사양: 원 충격.** S = 원 수출 YoY (exp_yoy). 원본 보고 숫자와 비교용이며, 판정에는 쓰지 않는다.

## 가설과 보정
- H1: β₁+β₃ = 0 (외환노출 법인 전체 반응). H2: β₃ = 0 (노출 − 비노출 차이).
- 시차 h = 0~12 (13개). 가설별로 13개 시차에 Holm 보정, 유의수준 0.05 (양측).
- 사전추세 점검 h = −3, −2는 따로 보고한다 (보정 묶음에 넣지 않음). 유의하면 주의 사항으로 적는다.

## 결과를 매칭 모델에 반영하는 규칙 (라벨만 바꿈)
- 단계 정의(k 구간)와 트리거 규칙은 바꾸지 않는다. 바꾸는 것은 근거_타이밍 라벨뿐이다.
- 적기(k=3~6)는 h=3~6, 정점·유지(k=7~12)는 h=7~12를 본다. 주 사양 H1의 Holm 보정 결과로:
  - 해당 시차가 모두 유의 → "요구불 반응 추정 (h=a~b 유의, 상품 효과 아님)"
  - 일부만 유의 → "요구불 반응 일부 시차만 유의 (h=…)"
  - 하나도 유의하지 않음 → "요구불 반응 근거 약함 (Holm 보정 후 유의 시차 없음)"
- 관찰(h≤2)은 "반응 전 구간 (h≤2)", 장기둔화는 "근거 범위 밖 (h≥13 추정 안 함)"으로 둔다.
- 보고 수치는 "수출 YoY 10%p 하락 시 h개월 뒤까지 요구불 누적 로그 변화(≈%)"로 표기한다.
