## 0. 배경 — 이번 분석에서 새로운 것
기존 주 결과 식은 이미 비노출 법인을 포함한다:
  ln(D+1)_{t+h} − ln(D+1)_{t−1} = α_i + 달력월 + β1·X + β3·(X×노출) + ε  (X = 보정YoY ÷ 10)
보고한 −3.9%(6개월), −5.0%(12개월)는 β1+β3(노출 법인의 전체 반응)이다. 노출−비노출 차이 β3는 이미 추정되어 있다.
이번 분석이 새로 하는 것은 **통제 강화**다: 달력월 더미 → **지역×연월 FE**(지역 공통 충격·경기·금리·달력 흡수), **노출×영업일수차** 추가.
이 데이터로 β3를 이미 본 적이 있으므로 사전 설계가 아니라 **사후**다.

기존 β3 기준값 (주_보정충격, h=6): +0.0362 (10%p당) = **+0.362 (100%p당)**, p 0.004, Holm(h=0~12) 0.045.
환산: 10%p 하락 시 노출−비노출 차이 = (exp(−0.1·0.362) − 1)×100 = **−3.56%**.

## 2. 모형
  y_{i,t,h} = α_i + τ_{r(i),t} + β3^h (S_i × X_{r,t}) + γ^h (S_i × 영업일수차_t) + ε

- α_i 법인 FE, τ 지역×연월 FE. β1(X 단독항)은 τ에 흡수되어 추정하지 않는다.
- h = −6 ~ 12, h = −1은 기준이라 제외. h마다 따로 회귀(국소투영).
- 표준오차: 법인·연월 이중 군집 (Cameron–Gelbach–Miller, 파트3 `twoway_p`와 같은 소표본 보정). p·CI는 t(G_min − 1).
- 다중검정: β3의 h = 1~12 p값에 Holm.

| 모형 | 표본·가중 | 윈저라이즈 | 역할 |
|---|---|---|---|
| **A 주** | 대구·경북 전체 법인, 가중치 없음 | h마다 y를 1%/99% 분위로 절단 (기존과 동일) | **판정** |
| A-원YoY | A와 같음, X = 원 YoY | 1/99 | 확인용 (β3가 A와 같은지) |
| A-NW | A와 같음 | 없음 | 참고 (대출 원본과 맞춤) |
| A-양수 | A와 같음, 단 잔액_{t−1} > 0 이고 잔액_{t+h} > 0 인 관측만 (예금 파트 `run_lp(positive_only=True)`와 같은 조건) | 1/99 (조건 적용 후 표본에서) | 참고 (0↔양수 전환이 β3를 만드는지 확인) |
| B 매칭 | 매칭 1:3 표본, 매칭 가중치 | 1/99 | 강건성 (보고만, 판정 안 함) |

## 3. 사전추세
- **주 검정:** 모형 A에서 h = −6~−2의 β3가 모두 0이라는 결합 Wald 검정. h별 회귀의 영향함수(FE 제거 후 설명변수 × 잔차)를 법인·연월·법인×연월 군집으로 합쳐 h 사이 공분산을 구하고 χ²(5) p값(과 F(5, G_min−1) p값)을 보고한다.
- **결합검정 검산:** 합친 공분산의 대각 SE가 h별 이중 군집 SE와 일치하는지 출력한다. 다르면 결합검정 결과를 보고하기 전에 먼저 알린다.
- **원본 방식(대출과 같은 형태):** 종속 ln(D_{t−1}+1) − ln(D_{t−7}+1) (나중 − 이전, 6개월 창이라 h=6과 기간이 맞음), 한 번 회귀, 식·표본·윈저라이즈는 모형 A와 같음. 모형 B에서도 같은 회귀를 보고한다.
- **부호 주의:** LP 음수 h의 종속변수는 ln_{t+h} − ln_{t−1} (이전 − 나중)이다. 사후 효과와 같은 방향의 사전 추세가 있으면 음수 h의 β3는 **반대 부호**로 나온다. 원본 방식은 나중 − 이전이라 같은 방향이면 **같은 부호**다. 그림 설명에도 적는다.

## 4. 보고 단위
- β3: 수출 YoY 1(=100%p)당 로그 변화 (대출 REPORT와 같은 척도). 기존 주 결과(10%p당)는 ×10으로 바꿔 나란히 적는다.
- 환산 열: 10%p 하락 시 노출−비노출 차이(%) = (exp(−0.1·β3) − 1)×100.
- 기존 β1+β3(−3.9%, −5.0%)는 "노출 법인 전체 반응"이라 β3와 다른 양임을 표에 명시한다.

## 5. 해석 규칙 (결과 보기 전 고정, 모형 A h=6만으로 판정)
- **유지:** h=6 β3가 기존 β3(+0.362)와 같은 부호(양수, 수출 하락 시 노출 법인 요구불이 상대적으로 감소)이고 |β3| ≥ 0.181 (기존 크기의 절반 이상)
- **약해짐:** 부호는 같지만 |β3| < 0.181
- **뒤집힘:** 부호가 반대
- 판정과 별도로 이중 군집 p, 95% CI, Holm(h=1~12), 사전추세 두 방식, 모형 B 결과를 함께 보고한다.
- 모형 B의 h=6 β3 부호가 A와 반대이면 REPORT 한계에 명시한다.
- A-양수: REPORT에 A와 A-양수의 h=6 β3를 나란히 둔다. A-양수에서 효과가 사라지면(A와 부호가 같고 |β3| ≥ |A h=6 β3| / 2 가 아니면) 한계에 "계좌 잔액 0 전환에서 나온 효과일 가능성"을 적는다.
- 사전 추세 연장 기준 (**원본 방식 β3pre에만 적용**): 모형 A의 원본 방식 β3pre가 A h=6 β3와 같은 부호이고 |β3pre| ≥ |A h=6 β3| / 2 이면, REPORT 한계에 "사후 차이가 사전 추세의 연장일 가능성"을 적는다.
- "확정" 표현은 쓰지 않는다.
