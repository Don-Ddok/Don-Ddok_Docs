## 2. 주 분석: 요구불 입금·출금 (C1과 같은 사양)
  ln(F_{i,t+h}+1) − ln(F_{i,t−1}+1) = α_i + τ_{r(i),t} + β3^h (노출_i × X_t) + γ^h (노출_i × 영업일수차_t) + ε
- F = `요구불입금금액`(판정) / `요구불출금금액`(보고만). 월 흐름 금액의 t+h월과 t−1월 값을 비교한다(정확히 그 달 관측이 있을 때만).
- 법인 FE + 지역×연월 FE, 0 이하는 0으로 두고 ln(+1), 제외 없음. 윈저라이즈 h마다 1%/99%(가중치 없는 분위). 가중치 없음.
- h = −6~12 (h=−1 제외). SE: 법인·연월 이중 군집(CGM, harmonized와 같은 보정), p·CI는 t(G_min−1).
- 사전추세(입금·출금 모두 보고): LP h=−6~−2 결합 Wald(영향함수 합산, 검산 출력 — 대각 SE ≠ h별 SE이면 결합검정 보고 전에 먼저 알림)와 원본 방식(ln F_{t−1} − ln F_{t−7}, 한 번 회귀).
- 부호 주의: LP 음수 h는 "이전 − 나중"이라 사후 효과와 같은 방향의 사전 추세는 반대 부호로, 원본 방식은 같은 부호로 나온다.
- 보고 단위: 수출 YoY 10%p 하락 시 노출−비노출 차이(%) = (exp(−0.1·β3) − 1)×100.
- Holm: 판정은 h=6 하나라 쓰지 않는다. 곡선 해석용으로 h=1~12 Holm p를 함께 보고한다.
- MDE: 입금 h=6의 MDE(5% 양측, 검정력 80%, dof = G_min − 1, harmonized 부록 B와 같은 공식)를 ± 두 방향으로 보고한다.

### 판정 (요구불입금금액 h=6 하나로만, 결과 보기 전 고정)
가설: 수출이 꺾이면 노출 법인의 요구불 **입금이 상대적으로 줄어든다** (β3 > 0, 요구불 잔액 C1과 같은 부호).
순서대로 적용해 처음 맞는 것을 준다.
- **지지:** β3 > 0, 이중 군집 p < 0.05, 입금 LP 사전추세 결합 p ≥ 0.10, 사전 추세 연장 표시 없음, 그리고 원본 방식 β3pre가 **반대 부호이면서 p < 0.05가 아님** (harmonized 거치식처럼 충격 전 반대 방향의 유의한 차이 = 평균 회귀 가능성을 규칙이 놓치지 않도록)
- **약한 증거:** β3 > 0, p < 0.10
- **반대 방향:** β3 < 0, p < 0.10
- **근거 없음:** 그 외 (p ≥ 0.10)
- 사전 추세 연장 표시(등급과 별개): 원본 방식 β3pre가 h=6 β3와 같은 부호이고 |β3pre| ≥ |β3| / 2
- 출금 곡선은 판정하지 않는다.

## 3. 설계 점검: 충격 변수 타당성 — 지역 수출 YoY가 개별 기업 수출에 닿는가 (판정 없음, 보고만)
- 대상: EX 노출 법인(수출 실적이 있는 525곳)만. 비노출 법인은 수출 실적이 0이라 비교하지 않는다.
- **주 종속변수 (3개월 합계):** ln(수출실적 t+h−2 ~ t+h 합계 + 1) − ln(수출실적 t−3 ~ t−1 합계 + 1), h = 0~12. 두 구간의 3개월이 모두 관측될 때만 쓴다(하나라도 없으면 결측). 윈저 1/99. 수출 실적이 몇 달에 몰려 잡히기 때문이다.
- 참고(판정 문구에 쓰지 않음): 월 단위 ln(`외환_수출실적금액`+1)의 t−1 → t+h 변화, h = 0~12 (정확히 그 달 관측이 있을 때만, 윈저 1/99)
- 설명변수: 보정YoY (소수 척도)
- 통제: 법인 FE + 달력월 더미 + 영업일수차 (수준). 노출 법인만 보므로 지역×연월 FE를 넣으면 X가 흡수된다. **그래서 C1과 통제가 다르다.**
- SE: 법인·연월 이중 군집, t(G_min−1)
- 보고: h별 β, 95% CI, "지역 수출 YoY 10%p 하락 시 노출 기업 수출 실적 변화(%)" = (exp(−0.1·β) − 1)×100
- 해석 문구 (미리 고정, 주 종속변수 3개월 합계 기준):
  - h=0~3 네 시차의 p에 Holm을 적용해, β > 0이고 Holm 후 p < 0.05인 시차가 하나라도 있으면 → "지역 수출 충격이 노출 기업의 실제 수출에 반영된다"
  - 그 외 → "지역 수출 YoY와 개별 기업 수출의 연결이 이 데이터에서 약하다. 충격 변수 해석에 한계"
- 이 결과는 어떤 계정의 등급도 바꾸지 않는다.
- 한계(고정): EX 노출 법인의 수출 실적 > 0인 달은 42.9%, 법인별 중앙값 8개월(§0)이라 수출 실적이 몇 달에 몰려 잡힌다. 3개월 합계로도 0↔양수 전환이 결과에 섞인다.
