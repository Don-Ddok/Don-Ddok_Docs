# 법인 클러스터·수출–상품 관계 — 사전등록 (2026-09-29, 결과 확인 전 작성)

인사이트 관계 지도에 넣을 두 가지 새 집계의 방법이다. 결과를 본 뒤 특성·군집 수 선택 규칙·표시 기준을 바꾸지 않는다. 둘 다 **탐색적**으로 표시한다.

## B. 외환노출 법인 클러스터
- **대상:** 2025-12 외환노출 법인 598곳 (운영 정의: 최근 12개월 수출·수입 실적). 대구·경북, 금융·보험업 제외 (매칭 모델 대상과 같음).
- **특성 (법인별, 기간 2025-01~2025-12):**
  1. 수출 비중 = 수출실적 합 ÷ (수출+수입 실적 합)
  2. 외환 규모 = ln(1 + 수출+수입 실적 합)
  3. 요구불 규모 = ln(1 + 2025-12 요구불 잔액)
  4. 보유 여부 (2025-12 잔액 > 0, 0/1): 할인어음, 무역금융, 순수운전자금(운전자금대출 − 할인어음 − 무역금융), 시설자금대출, 저축성예금(거치식+적립식), 투자상품(수익증권+신탁), 퇴직연금
- **방법:** 특성을 표준화(z)한 뒤 k-means (n_init=20, random_state=0). 군집 수 k는 3~8 중 실루엣 점수가 가장 높은 값. 단, 가장 작은 군집이 10곳 미만인 k는 제외한다.
- **이름:** 사람이 붙이지 않는다. 전체 평균 대비 차이(z)가 가장 큰 특성 두 개로 자동 생성한다 (예: "수출 비중 높음 · 할인어음 보유").
- **프로필 (화면 표시):** 법인 수, 지역·세그먼트 구성, 업종_중분류 상위 3개(5곳 이상만 이름 표시), 특성별 평균·보유율, 요구불 중앙값, 규칙 기반 페르소나(A~E)와의 교차표.
- **하지 않는 것:** 군집별 수출 충격 반응 추정 (표본이 작아 별도 사전등록 없이 하지 않음). 개별 법인 정보는 화면·문서에 넣지 않는다.

## C. 수출–상품 관계 (보유 비율 비교)
- **대상:** 2025-12 관측 법인 7,389곳.
- **집단:** 세그먼트(수출형·수입형·비노출), 그리고 업종_대분류 중 법인 수 상위 6개.
- **상품(계정군):** B의 보유 항목 7개 + 당좌대출, 외상매출채권담보대출, 신용카드 사용(2025-12 사용액 > 0).
- **지표:** lift = 집단의 보유율 ÷ 전체 보유율. 네트워크에는 lift ≥ 1.2 또는 ≤ 0.8인 연결만 강조하고, 보유율과 법인 수를 함께 표시한다.
- 기술통계다. "수출형이라서 이 상품을 쓴다"는 인과로 해석하지 않는다.
